# Bomb Run

**Эскадрилья по вызову.** Наведите пульт на землю: на рельефе и крышах загорится красное кольцо цели. Подтвердите — завоет сирена, с горизонта придёт звено самолётов, откроет бомболюки и высыплет TNT ковром, кругом или сеткой. `/bombrun undo` вернёт всё, что разрушил налёт.

## Возможности (план)

- **Видимая эскадрилья.** Свои мультяшные самолёты: крутятся пропеллеры, тянутся следы в небе, открываются люки, по земле скользит тень, гул моторов с эффектом Доплера. Без символики реальных армий.
- **Наведение кольцом.** Кольцо цели ложится на рельеф и крыши. Колесо мыши меняет радиус, Alt+колесо — курс захода, ЛКМ подтверждает.
- **Консоль пульта.** ПКМ открывает «чемоданчик»: карта сверху, пресеты и красная кнопка под откидной крышкой.
- **Узоры сброса:** ковёр, круг, случайно в радиусе; позже кольцо, сетка, линия и спираль.
- **Ванильный TNT.** Бомбы — обычный TNT с меткой мода, поэтому работают моды на взрывы, оптимизаторы и приваты.
- **Откат.** Перед налётом зона цели запоминается, `/bombrun undo` восстанавливает её порциями.
- **Для серверов.** Лимиты живых бомб и взрывов за тик, права LuckPerms с лимитами по игрокам. В серверном режиме игроки без мода тоже видят падающий TNT.
- **Камеры для съёмки:** «за бомбой», «из кабины», «спутник».

К 1.0: три машины (лёгкий штурмовик, тяжёлый бомбардировщик и дирижабль), нагрузки от кластерных и зажигательных бомб до наковален, криперов на парашютах и фейерверков, режим выживания с крафтом пульта и перезарядкой.

## Команды (план)

| Команда | Что делает |
| --- | --- |
| `/bombrun strike <pos> [radius] [preset\|json]` | Налёт без пульта (сценарии, командные блоки, RCON) |
| `/bombrun cancel [raidId\|all]` | Самолёты разворачиваются, несброшенные бомбы отменяются |
| `/bombrun undo [raidId]` / `/bombrun snapshots` | Откат налёта / список снимков |
| `/bombrun preset save\|load\|list\|delete <name>` | Пресеты на сервере |
| `/bombrun stats` / `/bombrun reload` | Статистика / перечитать конфиг и данные |

Настройки, права и лимиты — в [PLAN.md](PLAN.md).
