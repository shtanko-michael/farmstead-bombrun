# Bomb Run — архитектурный план

> Рабочее название; slug `bomb-run` на Modrinth свободен (проверено 2026-11-25), CurseForge ещё не проверен.
> Запасные имена: Sky Strike, Squadron (тоже свободны на Modrinth). Мод вне очереди `ROADMAP.md`: решение
> владельца 2026-11-25 — Reel34 с TNT зашёл аудитории, зрители просят взорвать порт, небоскрёб, город. Мод
> одновременно инструмент для серии рилсов и публичный мод, который эти рилсы рекламируют.

## 1. Концепция

Игрок берёт **пульт** (Strike Remote), наводит курсор на землю — на ней светится кольцо цели с радиусом и стрелкой
захода. Подтверждает — воет сирена, с горизонта приходит **эскадрилья самолётов**, открывает бомболюки над
кольцом и высыпает TNT ковром, кругом или сеткой. Самолёты уходят за горизонт. Одна команда `/bombrun undo`
возвращает всё, что было разрушено.

**Аудитория:** любители «разрушительных» модов (тренд orbital strike), создатели роликов и шортсов, серверы с
ивентами и мини-играми, модпаки «песочниц».

## 2. Ниша (Modrinth, 2026-11-25)

| Мод | Скачивания | Что умеет | Чего нет |
| --- | --- | --- | --- |
| Orbital Strike Cannon (osc-dp) и клоны | 817 тыс., 422 тыс., 179 тыс., 106 тыс. | удочка → столб/кольца TNT с неба (тренд Wemmbu) | самолётов, наведения с радиусом, отката |
| Airstrike Mod | 25 тыс., 39 подп., MIT, все лоадеры, 1.20–26.3 | лазерный целеуказатель до 400 блоков, точечный удар, ковёр 100×100, кластер, дым, газ, ракета | по описанию самолётов нет — бомбы «падают с неба»; проверить в игре |
| Black Bombardment | 2,2 тыс., ARR, Forge/NeoForge | консоль-кейс с картой, 5 типов бомб, управляемый бомбардировщик | Fabric, отката, прав, качества подачи |
| Elytra Bombing | 43 тыс. | TNT с элитры | — |

**Вывод:** спрос на «дождь TNT» доказан (тренд orbital strike — сотни тысяч), а ниша «видимые самолёты +
красивое наведение» занята слабо. Отстраиваемся тем, чего нет ни у кого вместе:

1. **Видимая эскадрилья** с пропеллерами, следами в небе, открытием люков, звуком с затуханием и эффектом
   Доплера — то, что смотрится в ролике.
2. **Наведение курсором с кольцом и радиусом** прямо на рельефе + пульт-консоль с картой сверху.
3. **Откат** (`undo`) — для создателей роликов и серверных ивентов: взорвал, снял, вернул.
4. **Ванильный TNT** вместо своих бомб: совместим с модами взрывов, приватов и оптимизации; **серверный режим**
   работает и с ванильными клиентами (самолётов они не видят, но TNT падает).
5. **Права и лимиты** (LuckPerms) — можно ставить на сервер, не боясь гриферов.
6. **Камеры для контента:** «за бомбой», «из кабины», «спутник».

Самолёты — **оригинальные мультяшные модели Farmstead**, без опознавательных знаков реальных армий и стран:
это игрушка-разрушитель, а не военный симулятор (так проще с площадками и аудиторией 12+).

## 3. Функции

### M1 — вертикальный срез для съёмки (NeoForge 1.21.1)

- Пульт, наведение курсором, кольцо цели, радиус колесом мыши, подтверждение.
- Один тип самолёта, звено 1–12 машин, строй «клин»/«линия».
- Нагрузка: TNT с взрывом при ударе и TNT с ванильным фитилём (как в Reel34 — падает, шипит, взрывается).
- **Сила удара** на пульте (Ctrl + колесо): пять уровней `самолёты:шаг` от лёгкого (1 самолёт, шаг 8) до
  апокалипсиса (12 самолётов, шаг 1,6); бомб = площадь круга / шаг², до `raid.maxBombs` = 5000. Уровни и лимиты
  сервер шлёт клиенту (`ServerCapsPayload`).
- **Взрыв видно издалека:** ванила шлёт взрыв только игрокам ближе 64 блоков, поэтому сервер раз в тик рассылает
  точки взрывов (`BlastsPayload`, до `explosions.effectDistance` = 512). Клиент рисует огненный шар, пламя, искры,
  столбы дыма, тряску камеры и гром с задержкой по расстоянию.
- Узоры: ковёр (полосы по курсу), круг, случайно в радиусе.
- Сирена, гул моторов, свист бомб.
- Команда `/bombrun strike` для сценариев съёмки, `/bombrun undo`.

### 1.0

- Консоль пульта с картой сверху, пресеты, перетаскивание курса захода.
- Три самолёта: лёгкий штурмовик (быстрый, 8 бомб), тяжёлый бомбардировщик (медленный, 40 бомб), дирижабль
  (очень медленный, 200 бомб, «ковёр на весь город»).
- Нагрузки: TNT, кластер (разлетается на 8 малых), зажигательная (огонь), «мега» (одна бомба мощностью 12),
  наковальни, десант криперов на парашютах, фейерверки (мирный режим для праздников).
- Узоры: ковёр, круг, кольцо, сетка, линия, спираль, «текст» (после 1.0, если попросят).
- Камеры «за бомбой», «из кабины», «спутник».
- Режим выживания: пульт крафтится, бомбы берутся из инвентаря, перезарядка.
- Конфиг, экран настроек, права, 9+ языков, ветки всех версий шаблона.

### После 1.0

- Быстрые взрывы (пакетный расчёт разрушения) — см. §9, только если упрёмся в производительность.
- API для других модов: «вызвать налёт» и событие «налёт завершён».
- Зенитки/перехват — мини-игра для серверов.

| Этап | Цели | Почему |
| --- | --- | --- |
| M1 | NeoForge 1.21.1 | на ней capture-server рилсов (копия прод-мира) |

| M5 | весь набор Footprints: 1.20.1 Forge/Fabric, 1.21.x, 26.x NeoForge/Fabric | каркас `farmstead-mod-template` |

**Сторона:** нужен на обоих. Клиент без мода на сервере с модом — пускается, если включён
`server.vanillaClients = true` (тогда пульт — обычный предмет с компонентом данных, а не свой регистр; самолётов
не видно). Клиент с модом на сервере без мода — пульт работает только в одиночной игре.

**Зависимостей нет** (как Footprints): модели самолётов — свои `ModelPart`, без GeckoLib; экран настроек — свой.

## 5. Архитектура

```

 ┌──────────────────────────┐   RequestStrike   ┌──────────────────────────────┐
 │ remote/ TargetingState   │ ────────────────▶ │ strike/ StrikeValidator      │
 │  raycast, радиус, курс   │                   │  права, лимиты, дальность,   │
 │ remote/ TargetMarker     │ ◀──────────────── │  перезарядка, измерение      │
 │  кольцо на рельефе       │  StrikeDenied     │ strike/ RaidPlanner          │
 │ console/ ConsoleScreen   │                   │  заказ → план полёта         │
 │  карта сверху, пресеты   │ ◀──────────────── │ raid/ RaidManager (тик)      │
 │ raid/ ClientRaids        │  RaidStart(plan,  │  самолёты = виртуальные,     │
 │  позиция = f(план, t)    │     startTick)    │  точки сброса по времени     │
 │ render/ PlaneRenderer    │                   │ payload/ BombDropper         │
 │ render/ ContrailRenderer │ ◀──────────────── │  ванильный PrimedTnt + флаги │
 │ sound/ EngineSound,      │  RaidEnd          │ payload/ ImpactWatcher       │

 │ camera/ BombCam, CockpitCam                  │ payload/ ExplosionBudget     │
 └──────────────────────────┘                   │ undo/ RaidSnapshot, Restorer │
                                                │ command/ /bombrun …          │
                                                └──────────────────────────────┘
```

### 5.1 Главное решение: самолёты — не сущности

Самолёт пролетает 400+ блоков, большая часть пути — над незагруженными чанками, где сущность замёрзнет или
пропадёт. Поэтому **самолёт — это строка в плане налёта**, а не `Entity`:

- сервер один раз считает **детерминированный план**: для каждой машины — прямая (вход, выход), высота, скорость,
  момент старта, список точек сброса с тиками;
- клиенту уходит **один пакет** `RaidStart(raidId, plan, startTick)`; клиент рисует самолёт в позиции
  `plan.position(gameTime − startTick + partialTick)` — плавно и без трафика;
- сервер в своём тике только сбрасывает бомбы, когда наступает тик точки сброса;
- чанки зоны цели держатся загруженными тикетом на время налёта (`raid.forceLoadTarget`), путь вне зоны не
  грузится вообще.

Плюсы: нет ИИ и коллизий, нет рассинхрона, нагрузка от самолётов ≈ 0, налёт переживает отход игрока; план
сохраняется в `SavedData`, и после перезапуска сервера налёт продолжается или отменяется (`raid.resumeOnRestart`).

### 5.2 Бомбы — ванильный TNT

`BombDropper` создаёт обычный `PrimedTnt` с начальной скоростью самолёта (бомба летит по дуге вперёд, как
настоящая) и помечает его своим attachment/`CompoundTag` (`bombrun:payload`, `raidId`). Отсюда:

- совместимость с модами, меняющими TNT и взрывы, и с оптимизаторами;
- приваты работают сами: взрыв идёт через `level.explode` с источником-сущностью, срабатывают
  `ExplosionEvent` (NeoForge/Forge) и мишень миксина на Fabric → моды приватов отменяют разрушение;
- ванильный клиент видит обычный TNT — отсюда серверный режим.

`ImpactWatcher` раз в тик проверяет помеченные бомбы с нагрузкой «при ударе»: `onGround`, горизонтальная
коллизия или вода → фитиль 0. Нагрузки описаны данными (`payload/*.json`): мощность, фитиль, «при ударе»,
огонь, разлёт кластера, что спавнить вместо TNT (наковальня, крипер с парашютом, фейерверк).

### 5.3 Бюджет взрывов

Узкое место — не самолёты, а тысячи взрывов (Reel34 снимали на сервере с пониженным тикрейтом). `ExplosionBudget`:

- `limits.maxLiveBombs` — не больше N помеченных TNT в мире; сброс сверх лимита откладывается, самолёт
  «держит» бомбы (на клиенте это не видно);
- `limits.maxExplosionsPerTick` — бомбы, у которых фитиль дошёл до нуля сверх лимита, ждут следующего тика
  (фитиль ставится в 1);
- статистика в `/bombrun stats` и в F3: живые бомбы, взрывы/тик, мс на тик от мода.

### 5.4 Откат

Перед первым сбросом `RaidSnapshot` снимает цилиндр «радиус цели + запас на взрыв» × высота от
`minY` разрушения до верха построек:

- блоки — палитра + упаковка битами по секциям 16³ (как хранит сам чанк), NBT блок-сущностей отдельно;
- сжатие и запись в `world/data/farmstead_bombrun/snapshots/<raidId>.bin`, в памяти только индекс;
- `Restorer` возвращает блоки порциями (`undo.blocksPerTick`, по умолчанию 20 000), без обновлений соседей и
  без дропа, затем удаляет выпавшие предметы и оставшийся TNT в зоне;
- хранится последние `undo.keep` (по умолчанию 5) снимков на мир; `undo.maxBlocks` — лимит снимка, при
  превышении налёт идёт без отката с предупреждением.

Для рилсов это заменяет нынешний «слепок арены» в `siege.py`: раунд → `undo` → следующий раунд.

### 5.5 Наведение (клиент)

- **Луч** от камеры до `remote.maxRange` (по умолчанию 256, дальше — до границы прорисовки). Дальние чанки, которых
  нет на клиенте, луч не видит — сервер проверяет дальность и высоту цели заново.
- **Кольцо цели** (`TargetMarker`) — своя `RenderType`, квады по верхним граням блоков в радиусе (повторяет
  рельеф и крыши), пульсирующая кайма, сетка сброса пунктиром, стрелка курса захода; цвет — красный, если цель
  вне прав/дальности. Рендер — тот же приём, что у декалей Footprints (`common/render`).
- **Управление:** колесо — радиус (`remote.radiusMin..Max`), Alt+колесо — курс, ЛКМ — подтвердить,
  ПКМ — консоль, Shift+ЛКМ — повторить последний пресет. Клавиши переназначаются.

### 5.6 Консоль пульта

Экран в стиле «чемоданчика» с откидной крышкой красной кнопки:

- слева **карта сверху**: текстура из `MapColor` верхних блоков загруженных чанков (как у карты), строится в
  фоне по секциям, кэш на сессию; поверх — кольцо, курс (перетаскивается мышью), позиция игрока;
- справа: самолёт, число машин, строй, нагрузка, плотность, узор, высота, задержка/отсчёт; слоты пресетов;
- снизу **крышка кнопки**: клик поднимает крышку, второй — «Сброс». Анимация + щелчок + сирена.

### 5.7 Рендер и звук

- **PlaneRenderer** — `ModelPart`-модели из Blockbench (экспорт в Java-определение, своё), пропеллеры, люки
  открываются за 2 с до зоны, мигающие навигационные огни, лёгкий крен на развороте строя. Рисуется после
  сущностей, отсечение по фрустуму; дальше `render.planeLodDistance` — упрощённая модель.
- **ContrailRenderer** — ленты из точек (не частицы, чтобы не упираться в лимит частиц и «Частицы: минимум»),
  расширяются и тают за `render.contrailSeconds`.
- **Тень самолёта** — мягкое пятно-декаль на земле под машиной (дёшево и очень «киношно»).
- **Звук:** зацикленный гул мотора на каждый самолёт (до `sound.maxEngines`, дальние сливаются в один «гул
  эскадрильи»), высота тона от радиальной скорости (Доплер), свист падения на первых N бомбах налёта, сирена в
  точке цели на время отсчёта. Звуки — `farmstead-mod-tools/sounds` (ElevenLabs SFX), проверка пачкой.

### 5.8 Камеры

Клиентская подмена точки обзора (без своей сущности в мире): «за бомбой» — следует за первой бомбой до взрыва и
задерживается на 2 с; «из кабины» — позади ведущего самолёта; «спутник» — сверху на цель. Включаются из консоли
или клавишами, выключаются Esc. Это и функция для игроков, и инструмент съёмки.

### 5.9 Команды

| Команда | Что делает |
| --- | --- |
| `/bombrun strike <pos> [radius] [preset\|json]` | налёт без пульта (сценарии, командные блоки, RCON) |
| `/bombrun cancel [raidId\|all]` | самолёты разворачиваются, несброшенные бомбы отменяются |
| `/bombrun undo [raidId]` / `/bombrun snapshots` | откат налёта / список снимков |
| `/bombrun preset save\|load\|list\|delete <name>` | пресеты на сервере |
| `/bombrun stats` / `/bombrun reload` | статистика / перечитать конфиг и данные |

Сообщения команд и отказы — `Component.translatable`; в серверном режиме с ванильными клиентами текст
выбирается по языку игрока (как в серверных модах монорепо).

### 5.10 Сеть

| Пакет | Направление | Содержимое |
| --- | --- | --- |
| `RequestStrike` | C→S | цель, радиус, курс, пресет или параметры |
| `StrikeDenied` | S→C | ключ причины + параметры (нет права, перезарядка N с, вне дальности, лимит) |
| `RaidStart` | S→C (игроки в радиусе прорисовки) | `raidId`, план, `startTick` |
| `RaidCancel` / `RaidEnd` | S→C | `raidId` |
| `ServerCaps` | S→C при входе | лимиты и разрешённые нагрузки — чтобы консоль показывала только доступное |

### 5.11 Данные и пакеты ресурсов

- `data/<ns>/bombrun/planes/*.json` — скорость, высота по умолчанию, вместимость, интервал сброса, модель, звук;
- `data/<ns>/bombrun/payloads/*.json` — см. §5.2;
- `data/<ns>/bombrun/patterns/*.json` — параметры встроенных узоров;
- `assets/<ns>/bombrun/models/*` — модели самолётов (модпакер может добавить свой самолёт без кода).

## 9. Производительность — цели и риски

| Что | Цель |
| --- | --- |
| Самолёты, клиент | ≤ 0,3 мс/кадр на 12 машин с лентами |
| Самолёты, сервер | ≈ 0 (план, без сущностей) |
| Снимок отката | ≤ 1 с на 4 млн блоков, вне главного потока (чтение секций — в тике порциями) |
| Налёт 2000 TNT | сервер не падает ниже 10 TPS при лимитах по умолчанию |

| Риск | Что делаем |
| --- | --- |
| Тысячи взрывов кладут TPS | §5.3 бюджет; для рилсов — пониженный тикрейт + ускорение в монтаже (как Reel34); «быстрые взрывы» — после 1.0 и только с флагом |
| Снимок большого города (небоскрёбы, 160k+ блоков постройки, цилиндр ~8 млн) | упаковка секций, запись в фоне, лимит `undo.maxBlocks`; замер на сцене «город» до M2 |
| Сервер отменяет взрыв (приват), а клиент видел сброс | бомба взрывается без разрушения — честно и понятно |
| Модели и рендер ломаются на 26.x (новый пайплайн) | та же абстракция рендера, что у Footprints; 26.x — отдельная ветка Stonecutter |
| Площадки режут «военный» контент | мультяшные самолёты без символики, формулировки «разрушитель построек», без людей-жертв в рилсах |
| Airstrike Mod добавит самолёты | наша ставка — подача, откат, сервер-готовность и рилсы как реклама; выпустить M2 быстро |

## 10. Тест-план

- **Юнит:** `FlightPlan` (позиции по времени, точки сброса покрывают круг/ковёр/сетку, детерминизм), упаковка
  снимка (туда-обратно), валидатор (лимиты, meta, перезарядка).
- **GameTest:** налёт 1 самолёт / 10 бомб в загоне → блоки разрушены → `undo` → мир байт-в-байт как до;
  `explosions.breakBlocks=false` → блоки целы; нет права `payload.mega` → отказ с ключом.
- **Тест-матрица** (`farmstead-mod-tools`): клиент заходит по quickPlay, RCON `/bombrun strike`, скриншот
  в момент пролёта, в логе нет ошибок.
- **Вживую на capture-server:** налёт на копию Reel34-замка, замер TPS и времени отката, скриншоты в чат.

## 11. Рилсы — серия 6 «Взрываем»

Мод снимается тем же стендом, что Reel34 (`game/cinematic-mod/tools/reels/s3/siege.py` → новый `raid.py`):
сценарий шлёт `/bombrun strike …` по RCON, раунды разделены `/bombrun undo` вместо слепка арены.

| # | Идея | Постройка |
| --- | --- | --- |
| 1 | Сколько самолётов нужно, чтобы стереть порт? 1 → 3 → 6 → 12 | порт со складами, кранами, кораблями (схемы mcpehub / ИИ-строитель) |
| 2 | Небоскрёб против дирижабля | один высотный небоскрёб |
| 3 | Целый город с небоскрёбами — ночной налёт с сиреной | город (SimpleGen grand / схемы) |
| 4 | Мост с домами: точечный удар против ковра | мост |
| 5 | Что выдержит: дерево, камень, обсидиан — под ковром | три башни |
| 6 | Пульт крупным планом: «нажал кнопку — и…» (хук-ролик о самом моде) | любая из прошлых |

До выхода мода в конце роликов — плашка «Мод скоро бесплатно — подпишись»; после — «Bomb Run на Modrinth».
Каждый ролик сдаётся с пакетом публикации (`video/REELS.md`, §11).
